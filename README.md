# soomin007.github.io

게임 허브. 인스타 프로필에 거는 링크 하나가 여기로 온다.

**라이브: https://soomin007.github.io/**

홈은 상점(피처드 캐러셀 + 캡슐 그리드), 게임을 누르면 **그 게임의 세계관 테마로 소개 페이지가
펼쳐진다** (`#g/<id>` 해시 라우팅. ENIGMA는 1942 기밀문서, SYOTOS는 양피지, Be the Bee는 벌집,
Eyes on You는 상황실 HUD, 적자생존은 생태 도감). 클로드 디자인 v3 시안을 바닐라로 이식한 것.
**모든 화면은 다크 베이스**: 게임 세계의 밝은 재질(종이·양피지·벌집)은 페이지 배경이 아니라
어두운 무대 위에 조명을 받은 오브젝트(스크린샷 액자)로 표현한다. 홈↔상세는 크로스페이드로 전환된다.

## 구조

```
index.html        뼈대. OG 태그, 폰트 로드, 홈/상세 컨테이너
styles.css        홈 + 상세 테마 5종(.t-enigma/.t-sand/.t-bee/.t-hud/.t-eco) + 범용(.t-plain)
games.js          게임 데이터 배열. 앞으로 유일하게 손댈 파일
app.js            games.js 를 읽어 홈·상세를 그림 + 해시 라우팅 + 기기/유입 경로 적응
assets/           게임별 캡슐 이미지 (1232x706 webp)
og.png            카톡·인스타 공유 썸네일 (1200x630)
icon.png          파비콘 (256x256)
DESIGN_HANDOFF.md 디자인 도구에 넘기는 브리프 (제약·데이터·에셋 URL)
```

빌드 과정이 없다. HTML/CSS/JS 정적 파일뿐이라 push 하면 바로 반영된다.

## 적응형 동작

- **반응형**: 375px~1920px. 폰에선 캐러셀 화살표가 숨고 스와이프·점으로 넘긴다.
- **기기**: 터치 기기에선 `mobile: true` 게임이 먼저 정렬된다. 키보드 필요 게임엔 "키보드 필요" 배지.
- **유입 경로**: `?from=insta` `?from=github` `?from=itch` 쿼리(또는 referrer 자동 감지)로
  상단 환영 배너가 바뀐다. 인스타 프로필에는 `https://soomin007.github.io/?from=insta` 를 걸면 된다.
- **라우팅**: 카드를 누르면 `#g/<id>` 상세로. 브라우저 뒤로가기·Escape·"← 목록으로" 전부 홈 복귀.
  전환은 View Transitions 크로스페이드(0.3s, 미지원 브라우저·reduced-motion 은 즉시 전환).
- **모션**: `prefers-reduced-motion` 이면 자동 회전·연출 애니메이션이 꺼진다.

## 게임 추가

1. 캡슐 이미지 하나 생성 (대표 스크린샷/키아트 → 16:9):
   ```
   ffmpeg -y -i <원본> -vf "crop=...,scale=1232:706" -c:v libwebp -q:v 82 assets/<게임id>.webp
   ```
2. `games.js` 의 `GAMES` 배열에 항목 추가. 나머지 파일은 손대지 않는다.
   필드 설명은 games.js 상단 주석이 단일 진실. 핵심만:
   - `theme`: 상세 테마. `'enigma'|'sand'|'bee'|'hud'|'eco'` 또는 **빈 문자열(범용 다크 테마)**.
     새 게임은 일단 `""` 로 두면 게임색 포인트의 무난한 상세가 나온다. 전용 테마를 원하면
     styles.css 에 `.t-<이름>` 블록을 추가하고 app.js 의 THEMES 에 등록.
     **새 테마도 다크 베이스를 지킨다** (밝은 재질은 배경이 아니라 액자·패널로).
   - 문구는 표준 안내체(합쇼체)로. em dash(U+2014)는 쓰지 않는다.
   - `facts`: 상세의 표. **검증된 사실만**. 플레이 시간 등 수치를 지어내지 않는다.
   - `tag`: 상세 우상단 연출 문구 (예: "제 41차 원정 기록").

배열 순서가 곧 데스크톱 화면 순서다. 처음 온 사람이 제일 쉽게 붙는 게임을 맨 위에 둔다.
