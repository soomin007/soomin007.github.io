## 세션 2 (AI 디자인 흔적 정리)

### 요약
사용자가 12월 15일 과제전까지 남은 일을 맡기면서, 가운데 점이나 고정폭 글씨처럼 전형적인 AI 디자인 티가 나는 곳을 고치고
앞으로도 그러지 말라고 했다. 과제전에는 이 사이트 링크 하나를 낼 것 같다고 한다(사용자). impeccable 의 craft-floor Refuse 목록을
기준으로 허브 홈, 소개 페이지 여섯 개, 섬, 전시관 스케치, 설문 페이지를 고쳐 배포했고, 같은 실수를 막는 전역 규칙과 검사 도구를 만들었다.

### 주요 변경
- `index.html`, `app.js`, `styles.css`, `games.js`, `timepick.js`: 상단 바의 영어 꼬리표를 "직접 만든 무료 게임 6개"로, 피처드의 장르를 제목 아래로,
  캐러셀과 뒤로 가기 화살표를 SVG 로 바꿨다. 흐린 글자색(`--faint`)을 없애고 `--dim` 을 카드 위 대비 4.5:1 로 올렸다. 쓰지 않던 웹 글꼴 세 벌을 뺐다.
  `games.js` 끝에서 `~` 묶음을 줄바꿈 없는 공백으로 바꿔 ENIGMA "다섯 가지", Otherside "단 한 번" 줄바꿈을 막았다
- `g/*/index.html` 여섯 개: 영어 섹션 꼬리표와 번호 꼬리표(RULE 1, STEP 1, 문서 №1)를 지우고 구호식 제목을 하는 일을 말하는 제목으로 바꿨다.
  ENIGMA 는 타자기체와 고정폭 대신 명조, Eyes on You 와 적자생존은 Pretendard 의 tabular-nums. 왼쪽 색 띠는 테두리나 색 칩으로,
  별점은 SVG 로, 데모 안 문구의 가운데 점은 쉼표로. 페이지 제목은 게임 이름만 쓴다
- `world/index.html`: "스케치" 표시와 검색 제외를 없애고 제목과 공유 정보를 넣었다. 카드 유리 흐림 제거, 장르를 제목 아래로, 개발 보류는 괄호로
- `hall/index.html`, `pick/`: 같은 기준으로 정리
- `tools/check-design.cjs` (새 파일): 가운데 점, 고정폭 글꼴, 넓힌 자간, 왼쪽 색 띠, 유리 흐림, 글리프, 제목 위 꼬리표를 찾는다
- `known-issues.md` #24, `DESIGN_HANDOFF.md`(절대 제약 8번과 현재 상태), `README.md`(tools, world 설명)
- 전역 `C:\Users\soomi\.claude\CLAUDE.md`: 가운데 점의 UI 라벨 예외를 없애고 "웹 디자인 규칙" 절을 새로 뒀다

### 결정 사항
- ENIGMA 의 기밀문서 분위기는 명조(Noto Serif KR)와 종이 소품으로만 낸다. "TOP SECRET" 도장과 타자 커서 연출은 뺐다.
- Be the Bee 의 딱딱한 오프셋 그림자는 보드게임 말의 두께를 흉내 내는 것이라 남겼고, 전역 규칙에도 그 예외만 적었다.
- See you on the other side 데모의 "곁의 표식: [ 또 · 봐 ]"는 "곁에 새긴 말: '또 봐'"로 바꿨다. 본편 화면의 원래 표기는 확인하지 못했다.
- 충전이 필요해!는 끝까지 만든 짧은 게임이라 상태를 live 로 둔다(개발 보류 리본은 미완성 게임에만).
- `midterm/` 은 이미 낸 중간 과제의 기록이라 손대지 않았고, 검사 도구도 이 폴더를 건너뛴다.
- 작업 사본에는 CRLF 파일과 LF 파일이 섞여 있다(`core.autocrlf`, 이번에는 `g/be-the-bee` 만 CRLF). 직접 짠 문자열 바꾸기 스크립트는 파일의 줄바꿈에 맞춰 패턴을 바꿔야 한다.
