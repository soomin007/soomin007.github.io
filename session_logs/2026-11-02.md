# 2026-11-02 세션 로그

## 요약
웹프로그래밍개론 개인 과제(11주차 마감) 방향을 정하는 아이디어 회의를 했다. 개발 일지 대신 게임을 직접 겪게 하는 공간을 만들기로 하고,
3D 전시관 스케치(`hall/`)와 육각 타일 섬 지도 스케치(`world/`)를 차례로 만들었다. 사용자가 처음 생각한 지도 방식을 바탕으로 섬에
디테일 세 단계를 넣었고, 새 게임 충전이 필요해!(outlet-villains)를 허브 목록에 더했다. 사용자 확인을 받아 커밋하고 배포했다.

## 주요 변경
- `hall/index.html` (새 파일): 반원으로 둘러선 부스 다섯 개. 부스를 누르면 카메라가 그 앞으로 가고, 플레이를 누르면 화면 속으로 들어가
  게임이 창 전체를 채운다. Be the Bee 부스 옆 보드는 소개 페이지의 `#devlog` 를 읽어 그린다
- `world/index.html` (새 파일): 육각 타일 섬. 땅을 누르면 말이 광장을 거쳐 길을 따라 뛰어간다. Be the Bee 길가에 일지 기둥 12개,
  땅마다 게임 세계의 지형과 대표 물건 하나, 규칙으로 깔리는 풀 포기와 돌멩이와 길 디딤판, 새와 연기와 반딧불, WebAudio 로 만든 소리,
  방문자 시각에 따른 낮과 저녁과 밤(`?time=` 로 미리 보기), PC 전용 빛 번짐과 미니어처 초점
- `games.js`: outlet-villains 항목. 캡슐 `assets/outlet-villains.webp`(제목 화면 캡처, 안내 글자 delogo),
  피처드 `assets/feat/outlet-villains.webp`(프롤로그 그림 2, 하단 그라데이션), 스크린샷 3장(프롤로그 그림 1, 3, 4)
- `known-issues.md`: #20 앱 브라우저 창이 가려지면 움직이는 화면을 검증할 수 없다
- `.claude/launch.json`: 로컬 미리보기 서버(python http.server 8130)
- 검증: Playwright 헤드리스로 PC(1440, 1280)와 폰(375, 320)에서 섬 전체 보기, 여섯 땅 순회, 개발 일지, 플레이와 복귀,
  낮과 저녁과 밤을 찍었다. 콘솔 오류 없음, 폰 카드와 윗줄 좌우 여백 20px, 가로 넘침 없음. 허브 목록 카드는 320, 360, 390, 1440 폭에서 확인

## 결정 사항
- 전시관보다 지도를 택했다. 갤럭시 2가 3D 허브 대신 월드맵을 쓴 이유(코스까지 가는 수고를 줄인다), SMB3 의 월드별 지형,
  Yacht Club 의 SMW 지도 분석이 근거다. 자유 이동은 넣지 않고 누르면 말이 알아서 간다.
- 섬을 육각 타일로 만든 것은 Be the Bee 일지의 "판이 바깥으로 자란다"에서 가져왔다. 새 게임은 `SLOTS` 뒤에 저절로 자리를 얻는다.
- 디테일은 손으로 놓지 않고 규칙으로 생기게 했다(Townscaper, Tiny Glade, Dorfromantik 조사).
- 적자생존은 빼지 않고 공사 울타리를 두른 땅으로 남겼다. 땅 여섯 개가 육각형의 여섯 방향과 맞는다.
- Eyes on You 는 데모 링크를 유지한다. 정식판은 개발 중이고 9월 11일 이후 커밋이 없다. 끝까지 플레이되는 것을 확인하면
  `games.js` 의 play 링크 한 줄만 바꾸면 된다.
- outlet-villains 의 mobile 은 false 로 두었다. README 에는 휴대폰 방향 버튼이 있다고 되어 있지만, #12 규칙대로 실기기에서
  한 판 끝까지 해 본 뒤에만 true 로 바꾼다.
- 땅을 볼 때 카메라는 광장 쪽에서 바깥을 본다. 처음에는 늘 남쪽에서 봐서 남쪽 땅의 건물 뒷면이 보였다.

## 이어서 (배포 뒤)

- 사용자가 충전이 필요해!는 폰을 지원하지 않기로 확정했다. `games.js` 에 ENIGMA 와 같은 폰 미지원 안내(note)와 `환경: PC` 를 넣었다.
- 로컬 브라우저 창의 섬 지도에 새 게임이 안 보였다(사용자 지적). 창이 캐시에 남은 예전 `games.js` 를 쓰고 있었다.
  미리보기 서버를 캐시를 막는 `.claude/serve.py` 로 바꾸고, 남아 있던 캐시를 한 번 비운 뒤 여섯 땅이 모두 보이는 것을 확인했다.
  known-issues #4 를 이 경우까지 보강했다.
- 섬이 뿌옇고 흐려 보인다는 지적을 받았다(자원 절약 때문이냐는 질문). 해상도는 정상이었고, 고정 거리 안개와 ACES 톤 매핑,
  PC 화면의 강한 미니어처 흐림과 빛 번짐이 원인이었다. 안개를 카메라 거리에 맞춰 옮기고, NeutralToneMapping 으로 바꾸고,
  흐림(2.2 → 0.9)과 빛 번짐(문턱 0.86 → 0.95)을 줄였다. 밤 조명도 조금 밝혔다. known-issues #21.
- 위 수정도 사용자 확인을 받아 커밋하고 배포했다. `.claude/serve.py` 와 `launch.json` 은 로컬 설정이라 커밋하지 않았다.
- 실제 폰과 인스타그램 인앱 브라우저에서 섬의 첫 로딩과 프레임을 확인하지 않았다.
