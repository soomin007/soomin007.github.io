# 2026-10-13 세션 로그

## 요약
웹프로그래밍개론 중간 과제(허브 위에 `/pick/` 추천 페이지를 올리는 MVP)의 핸드오프 문서를 검토하고,
추천 후보 게임들의 기기 지원·세션 길이를 각 게임 저장소에서 조사했다. 조사 중 허브의 ENIGMA 모바일
표기 오류를 발견해 고쳐 배포했다.

## 주요 변경
- `games.js`: ENIGMA `mobile: false`, 환경 "PC", 스마트폰 미지원 안내 문구 추가
- `g/enigma/index.html`: 메타 칩 "폰 · PC 모두" → "PC"
- `known-issues.md`: #12 mobile 표기는 실기기 확인 후에만 붙인다
- `webprog-midterm-handoff.md`: 조사 결과·결정 반영 (비공개, 커밋 안 함)
- `.gitignore` 신설: 핸드오프 문서 제외

## 결정 사항
- 과제 작업은 개인 폴더가 아니라 허브 레포에서 진행. 다른 게임 폴더는 읽기 전용으로 참조
  (작업 범위를 좁게 유지, 세션 여러 개는 토큰 낭비).
- 플레이 시간 기준은 "중간에 그만둬도 손해 없는 지점까지"(세션 길이)로 통일하고 범위로 적는다.
  처음엔 게임마다 스테이지/런/한 판으로 단위가 섞여 비교가 불가능했다
  (레퍼런스: BoardGameGeek 범위 표기, HowLongToBeat 기준 분리, itch.io 평균 세션 길이).
- 다섯 게임 모두 언제든 멈출 수 있어 시간 질문은 필터가 되지 못한다. 후보는 기기 질문이 거르고,
  시간 질문은 결과 문구의 분량 안내만 바꾼다.
- 적자생존(보류)·EyesOnYou-Full(미등록)은 추천 후보에서 제외.
- 핸드오프 문서는 비공개 유지.

## 실수
- Be the Bee 에 중간 저장이 없다고 코드 확인 없이 단정했다. 실제로는 매 수 자동 저장 +
  이어하기 + 보관함이 있다 (`src/ui/game-save.ts`). 다른 저장소의 기능은 코드를 읽은 뒤에 말한다.
