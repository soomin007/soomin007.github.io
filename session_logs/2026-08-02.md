## 결정 사항
- 디자인 베이스라인 = 스팀 상점 (사용자 지시). 시그니처 = 게임별 색이 히어로 글로우·버튼·점을 물들임
- wip 게임은 "앞서 해보기" 리본 (스팀 오마주)
- 적응: 터치 기기(pointer: coarse)에서 mobile:true 우선 정렬, `?from=insta|github|itch` 또는
  referrer 로 환영 배너. 인스타 프로필에는 `?from=insta` 붙인 URL 권장
- 이모지 칩(📱⌨️)은 데스크톱 Chrome에서 격자 글리프로 깨져 텍스트("폰 OK"/"키보드 필요")로 교체
- 히어로 글로우가 만들던 375px 가로 스크롤은 `html,body{overflow-x:clip}` 으로 해결

## 세션 3: 클로드 디자인 v3 이식 (테마 상세 페이지)

사용자가 클로드 디자인에서 만든 `게임 허브 v3.dc.html`(DesignSync MCP로 읽음)을 바닐라로 이식.
support.js 는 디자인 도구의 React 런타임이라 배포 불가 → 순수 HTML/CSS/JS 재작성.

- 구조: 홈(피처드+그리드) ↔ 상세(#g/<id> 해시 라우팅). 상세는 게임별 테마:
  t-enigma(1942 기밀문서·타자기·검열바) / t-sand(양피지) / t-bee(벌집) / t-hud(상황실 스캔라인) /
  t-eco(생태 도감) + t-plain(새 게임용 범용)
- games.js 확장: theme·tag·facts·lineLong·yearLabel
- 이식하며 다듬은 것:
  - 카드 div role=button(키보드 핸들러 없음) → 실제 <a> 링크로
  - v3의 Be the Bee "한 판 약 10분"(미검증 수치) → "여왕벌·무한 모드"(README 근거)로 교체
  - **[hidden] 무력화 버그**: `.home{display:flex}` 가 UA `[hidden]` 을 이겨 홈·상세가 겹침
    → `[hidden]{display:none !important}` 로 해결 (증상: 상세 진입해도 홈이 그대로 보임)
  - **sandIn 의 filter:blur(8px) 제거**: 넓은 요소 전체 블러 애니메이션이 초기 페인트를
    수십 초 급락시킴(CDP 스크린샷 30s 타임아웃으로 발견). opacity+이동만 남김
  - Escape 복귀, 상세 진입 시 document.title 동기화, 홈 스크롤 위치 복원, reduced-motion 존중
- 검증: 5개 테마 전부 스크린샷 확인, Escape/뒤로가기/백버튼 라우팅, 375px 홈·상세 가로 스크롤 0

## 세션 4: em dash 전면 제거 + EyesOnYou 모바일 조작 확인

- 사용자 지시(전역 선호): 모든 프로젝트에서 em dash(U+2014) 완전 배제
  - 8개 파일 39건 치환: UI 문구는 `·`, 문서는 콜론·마침표, 연도 범위는 `~`(1942 ~ 2026)
  - DESIGN_HANDOFF 절대 제약에 "em dash 금지" 명시 (앞으로의 시안 문구도 걸러지도록)
- EyesOnYou 모바일 조작 조사: 터치 조작(TouchControls.gd)은 **EyesOnYou-Full(풀버전)에만** 있음.
  허브 카드가 가리키는 데모(EoY, /EyesOnYou/)는 키보드 전용이 맞음. 데모 코드의 "touch"는
  전부 몸통 박치기 데미지(TOUCH_DAMAGE)로 입력과 무관. games.js 의 mobile:false 유지.
