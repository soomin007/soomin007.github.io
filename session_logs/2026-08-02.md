- 이식하며 다듬은 것:
  - 카드 div role=button(키보드 핸들러 없음) → 실제 <a> 링크로

사용자 요구: 전 문구를 표준 어투로, 화면 간 트랜지션 추가, 밝은/어두운 배경 혼재 해소,

  promise 를 catch 안 하면 전환 스킵 시 콘솔에 InvalidStateError** → 조용히 삼킴.
- 전 문구 합쇼체 통일 (games.js 설명 포함), 유입 배너 strong+span 2줄 구조,

- 검증: ultracode 워크플로 15에이전트(5렌즈 발견 + 적대적 확인). 확정 13건 전부 반영:
  - **reduced-motion 의 `.d__main{animation:none}` 이 `.t-* .d__main`(0,2,0)에 짐** →
    `.detail .d__main` 으로 특이도 동률+후순위 승리 (high)
  - 대비 미달: enigma kicker #d4574e→#e06a5f, CTA 텍스트→#fff, hud #3d5483→#6b84b8,
    eco #4a6b57→#6f9480 (전부 WCAG 계산 검증)
  - 전환 도입으로 homeScrollY 캡처가 비동기로 밀린 경합 → hashchange 에서 동기 캡처
  - 닫기 시 hash="" push 로 뒤로가기 루프 → 홈에서 진입한 상세는 history.back() 으로 pop
  - 캐러셀: innerHTML 재생성 시 포커스 복원, hover/focus 중 자동 회전 정지(WCAG 2.2.2)

  - 기각 1건: enigma 스탬프 대비 (장식 요소라 WCAG 제외)
- 검증 한도(10) 초과로 무검증 통과된 5건(copy 3·js 2)은 메인 루프가 직접 코드 확인 후 적용,
